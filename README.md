# 🐒 Primata Species Guide

Projeto educacional inicial desenvolvido durante o processo de aprendizado em desenvolvimento web, com foco em estruturação de páginas, organização de conteúdo e prática de fundamentos de front-end.

Este projeto representa meu primeiro contato real com construção de sites funcionais, consolidando conceitos de HTML, CSS e organização de arquivos.

---

## 🧠 Propósito do projeto

O objetivo não foi criar um produto final ou comercial, mas:

- Praticar estruturação de páginas HTML
- Entender organização de projetos web
- Explorar separação de estilos em CSS modular
- Construir navegação simples entre páginas
- Desenvolver lógica básica de front-end
